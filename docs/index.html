Groentebox-kok

Upload een foto van je bezorgmail of brief. Je krijgt een vegetarisch weekmenu dat alles uit je box opmaakt, met wat het snelst bederft eerst.

Instellingen: API-sleutel

Deze site praat rechtstreeks met Claude via je eigen Anthropic API-sleutel. Maak er een aan op console.anthropic.com.

Je sleutel blijft alleen in deze browser (localStorage). Hij gaat nergens anders heen dan naar api.anthropic.com. Gebruik deze site niet op een gedeelde computer.
